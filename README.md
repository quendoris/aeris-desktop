# AERIS Desktop

Desktop application for AERIS (`.aeris`) maps.

This repository contains the Qt desktop frontend. The normative `.aeris` format, canonical cartographic core, storage/verifier contracts, source adapters, projection mathematics, and conformance fixtures live in the AERIS core repository.

The desktop application is intentionally a consumer of the core; it must not define an alternative interpretation of `.aeris`.
